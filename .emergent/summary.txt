**original_problem_statement:**
Create a mobile restaurant POS (Point of Sale) application designed to operate fully offline with a strong focus on privacy, security, and local data control.

PRODUCT REQUIREMENTS:
- **Offline First:** Must function completely offline.
- **Local Data:** All data (menu, tables, orders, bills, reports) stored locally on the device using SQLite.
- **Encryption:** Sensitive data and backups must be AES-256 encrypted.
- **Access Control (RBAC):** Role-based access for reports (Admin, Manager, Cashier, Captain).
- **Authentication:** PIN-based and Username/Password.
- **Features:**
    - Offline order taking with item-level hold for KOT printing.
    - Table management (open, merge, transfer, edit, delete).
    - Bill generation with inclusive CGST/SGST breakdown (5%) and restaurant branding.
    - Automatic Bluetooth KOT printing.
    - Secure local backup and restore.
    - Editable menu with categories and add-ons.
    - Part-payment option.
    - Order cancellation.
    - Concurrent orders on the same table.

**User's preferred language**: English

**what currently exists?**
A comprehensive, offline-first mobile POS system built with Expo. The application uses a local SQLite database for all operational data, ensuring full offline functionality.

Key implemented features include:
- Role-based authentication (Admin, Manager, Captain).
- A tab-based navigation system with role-based access control.
- Advanced table management: add, edit, delete (Admin only), and transfer orders.
- A sophisticated ordering system that supports multiple, independent orders on a single table simultaneously.
- A two-step billing process (Print Bill, Settle Bill) with support for part-payments and merged bills.
- An admin-exclusive reports dashboard with analytics that correctly update upon bill deletion.
- A Cancel Order feature available directly from the table screen.
- A custom theme (colors and branding) applied throughout the app, including the restaurant's name on bills.
- The foundation for Bluetooth KOT printing and secure backup/restore has been laid, with dedicated screens and graceful error handling for running in Expo Go.
